# COVID-19 India Tracking Dashboard

An interactive visual story and dashboard built using **Tableau** to analyze COVID-19 trends, state-level distributions, and vaccination metrics across India.

## Project Overview
This project visualizes pandemic data using advanced Tableau features to track infection rates, recovery statistics, and vaccination progress across various states and union territories.

## Key Features & Visuals
* **State-Level Map Distribution:** Implemented geographic filled maps to display regional impact and case density across India.
* **Dual-Axis Trends:** Tracked temporal patterns comparing daily active cases against recovery and mortality rates over time.
* **Vaccination Metrics:** Designed KPI cards and progress indicators to monitor vaccination campaign milestones.
* **Design Theme:** Utilized a cohesive 'Earth and Sky' custom color palette and layout structure for enhanced readability.

## Tools & Technologies Used
* **Tableau Desktop / Tableau Public** (Calculated Fields, Dual-Axis Charts, Parameters, Filters)
* **Data Visualization Best Practices** (Dashboard layout styling, interactive filtering, tooltips)
